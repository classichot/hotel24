What I would pick

Lacquer Red (1b) for HOTEL24. It is the only red in this set that clears 4.5:1, so the accent can carry small interface text — rate figures, warning labels, the "฿12,400 due" in the arrivals table — without dropping to a second, duller step. It also reads as Thai lacquer rather than software red, and it sits one notch away from the Modernist default, so nothing in the system has to be re-derived.

Pair it with Marigold (1e) as TOUR24's accent: same warm family, clearly a sibling and never confused with HOTEL24's operational red — which is the colour that means "something needs you now".
